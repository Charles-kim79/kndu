1. AI 활용 기본기

보안·프라이버시 · 환각·정확성 · 편향 — AI를 쓰기 전에 알아야 할 3가지 한계

핵심 개념
AI는 정답을 아는 도구가 아니라 그럴듯한 답을 만드는 도구입니다. 사람이 입력(보안·프라이버시)과 결과(환각·정확성, 편향)를 모두 점검합니다.
가능해지는 것

AI에 넣어도 되는 자료일까요?

개념
AI에 입력한 내용은 서비스에 저장되거나 학습에 쓰일 수 있습니다. 무엇을 넣을지는 사람이 정합니다.
공직 현장
업무 자료, 개인정보, 군사보안 사항은 입력하지 않는 것이 원칙입니다.

카드마다 「입력해도 됨」 또는 「입력 금지」를 고르세요.

0 / 5 맞힘
환각 · 정확성

AI는 왜 틀린 말을 자신 있게 할까요?

개념
환각(Hallucination)은 AI가 사실이 아닌 내용을 사실처럼 만들어 내는 현상입니다. 다음에 올 그럴듯한 말을 만드는 방식이라, 틀려도 말투가 똑같습니다.
공직 현장
보고서에 들어간 틀린 숫자·날짜·법령명은 그대로 결재선을 따라 올라갑니다.

틀렸다고 판단한 문장 2개를 누르고 「채점」을 누르세요. 막히면 힌트를 순서대로 보세요.

    편향

    같은 질문인데 왜 결과가 다를까요?

    개념
    편향(Bias)은 학습 데이터의 치우침이 결과에 그대로 나타나는 현상입니다. 이름이나 성별만 달라져도 표현이 달라집니다.
    공직 현장
    인사 평정, 민원 답변, 안내문, 정책 이슈에서 중립성 검토가 필요합니다.

    요청: "우수 직원 추천서를 한 문단으로 써 줘. (이름: 김민수 / 김민지)" — 성별에 따라 달라진 표현을 모두 누르고 「확인」을 누르세요.

    3. 엑셀 자료 검증 시스템 만들기
    
    
    엑셀 오류를 파악하고, 프롬프트 한 장으로 정리 도구를 만든다
    
  
    
  
    
    
    핵심 개념
    업무 도구는 코드를 몰라도 말로 요청해서 만들 수 있습니다. 어떤 오류를 어떤 규칙으로 잡을지 정확히 적는 것이 핵심입니다.
    
    
    가능해지는 것
    입력이 제각각인 엑셀 자료를 자동으로 정리하고 검증하는 도구를 AI로 만듭니다.
    
  
    
  
    이 실습을 마치면 엑셀 오류를 잡는 도구를 만드는 완성 프롬프트 한 장을 갖게 됩니다.
    

  
    
    
    1. 오류 파악
    엑셀에는 이런 오류가 생깁니다
    
    
    
      
    유형이런 모습생기는 문제잡는 방법
    
      
        
    날짜2025.10.2 · 20251007 · 25.10.09정렬과 기간 집계가 틀어짐YYYY-MM-DD 한 가지로 통일
    
        
    금액1,200,000원 · ₩ 850,000 · 85만원합계가 계산되지 않음숫자만 남기도록 통일
    
        
    부서명총무 · 총 무 과 · 정보화담당같은 부서가 따로 집계됨기준 이름으로 통일

    3단계 업무 자동화
    
      5. API 연결
      
    
      문서에 실시간 데이터를 연동해 스스로 갱신되는 스마트 문서
      
  
      
  
      
    
      핵심 개념
      API는 프로그램끼리 데이터를 주고받는 창구입니다. 주소 하나를 호출하면 날씨 같은 실시간 데이터를 받아 문서에 넣을 수 있습니다.
      
    
      가능해지는 것
      한 번 만들어 두면 열 때마다 최신 내용으로 바뀌는 스마트 문서를 AI로 만듭니다.
      
  
      

  
      
    
      1. 날씨 API 연결
      주소 하나로 실시간 날씨를 받아옵니다
      
    
      
      
      ① 요청날씨 서비스 주소를 호출합니다.
      
      
      ② 응답날짜별 데이터가 돌아옵니다.
      
      
      ③ 표시필요한 값만 골라 화면에 보여 줍니다.
      
    
      
    
      
      
      
      
      연결 중…
    
      
    
      ① 요청 주소
      
    
      ② 받은 데이터 (선택한 날짜)
      
    
      업데이트 지연 AI는 최신 정보가 바로 반영되지 않습니다. API로 실시간 데이터를 연결하면 이 한계를 보완합니다.
      
    
      공개 날씨 서비스 Open-Meteo를 사용합니다. 가입이나 키가 필요 없습니다. 연결이 안 되는 환경에서는 샘플 데이터로 전환되고 표시됩니다.
      
  
      

  
      
    
      2. 문서에 연결
      공문 속 안내 표의 날씨 칸이 실시간으로 채워집니다
      
    
      강수확률60%이상이면 실내 진행으로 전환
      
    
      
    
      지역과 날짜를 바꿔 보세요. 표시된 실시간 항목이 자동으로 바뀝니다. (가상의 예시 문서입니다)
      
  
      

  
      
    
      3. 내 문서에 적용
      프롬프트로 나만의 스마트 문서를 만듭니다
      
    
      국방대학교 체육대회 개최 공문을 웹 문서(HTML 파일 하나)로 만들어 줘.
- 전체 틀은 정부 공문 서식으로 해 줘: 기관명, 수신, 제목, 본문(1. 관련 / 2. 개최 안내 / 3. 문의처), 붙임, 끝, 발신 명의 순서야. 직인과 실명은 넣지 말고 '(가상의 예시 문서)'라고 표시해 줘. 대대 같은 편제나 '장병' 같은 표현은 쓰지 마.
- 본문 2번 아래에 안내 표(박스)를 넣고, 표에는 일시, 장소, 날씨, 진행 안내, 준비물 5개 행을 만들어 줘.
- 일시(오늘부터 7일)와 지역(논산 36.19/127.10, 서울 37.57/126.98, 대전 36.35/127.38)을 고르게 해 줘.
- 선택하면 Open-Meteo 날씨 API로 그날의 강수확률과 최고·최저 기온을 불러와 표의 '날씨' 칸에 표시해 줘. 호출 주소 예: https://api.open-meteo.com/v1/forecast?latitude=36.19&longitude=127.10&daily=precipitation_probability_max,temperature_2m_max,temperature_2m_min&timezone=Asia%2FSeoul&forecast_days=7
- 강수확률이 60% 이상이면 '장소'가 실내 체육관, '진행 안내'가 '우천 예상: 실내 체육관에서 진행'으로, 아니면 운동장, '예정대로 운동장에서 진행'으로 자동으로 바뀌게 하고, 준비물에도 실내화(우천) 또는 모자(맑음)가 반영되게 해 줘.
- 인터넷 연결이 안 되면 샘플 값을 보여 줘.
      
    
      Gemini 열기
      
    
      일반 Word·한글 문서는 한 번 쓰면 값이 고정됩니다. 실시간으로 바뀌는 문서는 웹 문서(HTML)로 만듭니다. 날씨 외에 환율, 미세먼지 같은 공개 데이터도 같은 방식으로 연결합니다.
      
  
      
  
      
    
      4. 파일로 저장
      저장한 문서도 실시간으로 열립니다
      
    
        
      
      1. Gemini가 만든 문서의 코드를 복사해 메모장에 붙여넣고 체육대회공문.html로 저장합니다. Gemini 화면에 다운로드 버튼이 있으면 그것을 써도 됩니다.
        2. 
      
      2. 저장한 파일을 더블클릭해, 인터넷이 연결된 브라우저로 엽니다.
        3. 
      
      3. 표의 날씨 칸이 실시간 값으로 채워지는지 확인합니다. 인터넷이 되지 않는 환경에서는 샘플 값이 표시됩니다.
        4. 
    
      
    
      
      
      저장 형식날씨 값
      
      
        
      HTML 파일열 때마다 최신 값으로 갱신됩니다. (인터넷 필요)
      
        
      PDF 파일 (브라우저 인쇄 → PDF로 저장)저장한 순간의 값으로 고정됩니다.
