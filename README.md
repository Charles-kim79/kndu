# AI 업무 역량 워크북

국방대학교 직무연수 「4차 산업혁명과 IT활용능력」 강의 후 혼자 따라 하는 실습 자료 (단일 `index.html`).
설치·로그인 없이 브라우저에서 동작하며, AI는 수강생 본인의 Gemini를 사용합니다.

- 구성: AI 활용 3단계 — 1단계 AI 이해와 검증(1번) · 2단계 프롬프트 활용(2~3번) · 3단계 업무 자동화(4~5번)
- 소재 교체: `index.html` 스크립트 상단의 `CONTENT` 객체만 수정합니다. (과정명, 강사 표기, 연도 포함)
- 번호 직링크: `#t1` ~ `#t5`
- 5번 날씨는 Open-Meteo 공개 API를 사용하며, 연결이 안 되면 샘플 값으로 전환됩니다.

ⓒ 2026 김철재. 강의 수강생의 개인 학습 외 목적(복제·외부 배포·게시·상업적 이용)의 사용을 금합니다.
